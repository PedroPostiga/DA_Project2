{\bfseries{Issue}}:\+ When no good split is found in the main optimization loop, the fallback code tries to find ANY splittable web. However, it uses the condition:\+ 
\begin{DoxyCode}{0}
\DoxyCodeLine{\textcolor{keywordflow}{if}\ (deg\ >\ bestOrigDeg\ ||\ (deg\ ==\ bestOrigDeg\ \&\&\ w.id\ <\ bestId))}

\end{DoxyCode}

{\bfseries{Fix}}:\+ Added explicit check for uninitialized state:\+ 
\begin{DoxyCode}{0}
\DoxyCodeLine{\textcolor{keywordflow}{if}\ (bestId\ ==\ -\/1\ ||\ deg\ >\ bestOrigDeg\ ||\ (deg\ ==\ bestOrigDeg\ \&\&\ w.id\ <\ bestId))}

\end{DoxyCode}

\begin{DoxyEnumerate}
\item {\bfseries{Array Index Out of Bounds}}:\+ When {\ttfamily disabled\+[w.\+id]\+} is accessed with an uninitialized or invalid {\ttfamily best\+Id}, and the comparison logic fails to properly bound-\/check, it can lead to accessing memory outside the {\ttfamily disabled} vector.
\item {\bfseries{Memory Safety}}:\+ The condition {\ttfamily w.\+id \texorpdfstring{$<$}{<} best\+Id} where {\ttfamily best\+Id == -\/1} bypasses normal tie-\/breaking and can cause the algorithm to select invalid candidates or skip valid ones.
