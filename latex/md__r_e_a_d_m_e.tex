\hypertarget{md__r_e_a_d_m_e_autotoc_md17}{}\doxysubsection{\texorpdfstring{T2.\+4 — Free Strategy (Linear Scan + Selective Eviction)}{T2.\+4 — Free Strategy (Linear Scan + Selective Eviction)}}\label{md__r_e_a_d_m_e_autotoc_md17}

\begin{DoxyItemize}
\item {\bfseries{{\ttfamily \doxylink{_algorithms_8cpp}{Algorithms.\+cpp}}}} — {\ttfamily allocate\+Free()} implements a custom strategy combining:\+
\begin{DoxyItemize}
\item {\bfseries{Earliest definition point first ordering:\+}} Processes webs by earliest definition point first (def\+Point order)
\item {\bfseries{Greedy assignment with eviction:\+}} When no register is free for a web, spills the interfering neighbor with the fewest program points (cheapest to reload), then retries assignment
\item {\bfseries{No explicit spill budget:\+}} Eviction decisions are made dynamically based on program point count
\end{DoxyItemize}
\item {\bfseries{Rationale:\+}} This approach minimizes spills by prioritizing long-\/lived webs (many program points) for registers, while short-\/lived webs (few program points) are cheaper to spill/\+reload. The def\+Point ordering approximates program execution order, improving spatial locality
\end{DoxyItemize}

If you are on Windows, you have to do this in the wsl terminal.


\begin{DoxyEnumerate}
\item Create a folder {\ttfamily build} with {\ttfamily mkdir build}
\item Go to folder "{}build"{} with {\ttfamily cd build}
\item Run {\ttfamily cmake ..} followed by {\ttfamily cmake -\/-\/build .}
\item Come to the project folder with {\ttfamily cd ..}
\item Run {\ttfamily ./\+build/\+\+DA\+\_\+\+Project2} for the interactive menu
\item Run {\ttfamily ./\+build/\+\+DA\+\_\+\+Project2 -\/b input/\+ranges.\+txt input/\+registers.\+txt output/\+allocation.\+txt} for the batch mode
\end{DoxyEnumerate}
