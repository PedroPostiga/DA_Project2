\doxysubsection{Detailed Description}
Builds and manages the web interference graph for register allocation. 

\doxylink{class_interference_graph}{Interference\+Graph} is a domain-\/specific layer on top of \doxylink{class_graph}{Graph$<$int$>$}. Each vertex in the underlying \doxylink{class_graph}{Graph$<$int$>$} stores a web ID (int), and the full \doxylink{struct_web}{Web} data is kept in a parallel vector indexed by that same ID.\hypertarget{class_interference_graph_autotoc_md0}{}\doxysubsubsubsection{\texorpdfstring{Why Graph$<$int$>$ and not Graph$<$\+Web$>$?}{Why Graph$<$int$>$ and not Graph$<$\+Web$>$?}}\label{class_interference_graph_autotoc_md0}
\doxylink{struct_web}{Web} objects are large and mutable — they are modified during spilling and splitting (T2.\+2, T2.\+3). Storing only the integer ID in the graph avoids copying and allows the full \doxylink{struct_web}{Web} data to be looked up in O(1) via the vector, from any graph traversal result.\hypertarget{class_interference_graph_autotoc_md1}{}\doxysubsubsubsection{\texorpdfstring{Why two directed edges per interference?}{Why two directed edges per interference?}}\label{class_interference_graph_autotoc_md1}
\doxylink{class_graph}{Graph$<$\+T$>$} models directed edges. An interference relation is symmetric (if web A interferes with web B, B interferes with A), so we add one edge in each direction. The degree of a node is then the size of its adjacency list, which correctly reflects the number of interfering webs.

Time complexity of \doxylink{class_interference_graph_ad68d7a95dbde1a1aa7e5dac96ff13b6e}{build()}:\+ O(\+W\texorpdfstring{$^\wedge$}{\string^}2 \texorpdfstring{$\ast$}{*} P \texorpdfstring{$\ast$}{*} log P) W = number of webs, P = average program points per web.

Builds the interference graph from a list of webs. 

For each web, adds a vertex with info = web.\+id to the underlying \doxylink{class_graph}{Graph$<$int$>$}. Then, for every pair of webs, calls \doxylink{struct_web_a1daf0ad084076fd059d0e66e75481125}{Web::\+interferes\+With()} and adds a bidirectional edge if they interfere.

Any previously built graph is cleared before building.

Time complexity:\+ O(\+W\texorpdfstring{$^\wedge$}{\string^}2 \texorpdfstring{$\ast$}{*} P \texorpdfstring{$\ast$}{*} log P)
