\doxysubsection{Detailed Description}
Generic, template-\/based graph data structure representing vertices and directed edges. 

This header defines the templates \doxylink{class_vertex}{Vertex}, \doxylink{class_edge}{Edge}, and \doxylink{class_graph}{Graph}, which form the structural foundation for the interference graph used by the register allocator.
