\doxysubsection{Detailed Description}
Defines core data structures for the register allocator (\doxylink{struct_live_range}{Live\+Range}, \doxylink{struct_web}{Web}, \doxylink{struct_algorithm_config}{Algorithm\+Config}). 

This header declares and documents the essential abstractions used throughout the project, including \doxylink{struct_live_range}{Live\+Range} (individual variable lifespans), \doxylink{struct_web}{Web} (unions of overlapping live ranges forming nodes in the interference graph), and \doxylink{struct_algorithm_config}{Algorithm\+Config} (parsed settings).
