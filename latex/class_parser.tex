\doxysubsection{Detailed Description}
Parses the live ranges input file and the algorithm configuration file. 

Responsibilities:\+
\begin{DoxyEnumerate}
\item Read and tokenize the live ranges file, producing \doxylink{struct_live_range}{Live\+Range} objects.
\item Merge overlapping live ranges of the same variable into \doxylink{struct_web}{Web} objects using a greedy algorithm.
\item Read the algorithm configuration file (register count, algorithm type).
\end{DoxyEnumerate}

The webs produced here become the nodes of the interference graph, which is built separately by \doxylink{class_interference_graph}{Interference\+Graph} using \doxylink{class_graph}{Graph$<$int$>$} as its base.\hypertarget{class_parser_autotoc_md2}{}\doxysubsubsubsection{\texorpdfstring{Live Ranges File Format}{Live Ranges File Format}}\label{class_parser_autotoc_md2}

Parses the live ranges input file. 

Reads variable names and their associated live ranges, applies the \textquotesingle{}+\textquotesingle{}/\+\textquotesingle{}-\/\textquotesingle{} markers, then merges overlapping ranges for each variable into webs.
